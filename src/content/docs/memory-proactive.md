## 会话记忆

聊天记录保存在用户后端绑定的 D1。群聊和私聊通过独立会话标识分开，平台、会话类型与目标参与标识，避免串用上下文。

核心/插件命令通常不会进入 AI 历史；关键词固定 Markdown 回复也不会作为 assistant 文字加入历史。普通消息是否记录还受相应记录开关影响。

## 未 @ 消息记录

群中是否记录没有 @ 机器人的消息，由 `CONTEXT_RECORD_UNMENTIONED` 控制。能收到群全量消息还取决于 QQ 平台事件权限与订阅。

记录和回复是不同动作：保留现场信息不代表每条消息都要回答。按实际群聊需要设置，避免不必要的数据库读取和模型请求。

## 主动发言

主动发言先看 `PROACTIVE_GROUPS` 中的群覆盖设置，再使用 `PROACTIVE_ENABLED` 默认值。关闭的会话跳过对应主动发言状态查询。

建议先在少量测试群启用，结合人格、回复长度、群消息权限和模型成本调整。平台权限不足时，单改开关不会补出不存在的消息事件。

## 清除和维护

核心提供清除会话上下文的相关命令。数据管理可检查数据库与结构，界面不提供任意删除记录。

更换 D1 绑定不会自动迁移旧记录，原库会保留。代码回滚也不会回滚数据库。

详情见 [数据库与存储](/docs/storage/) 和 [更新与恢复](/docs/upgrades/)。
