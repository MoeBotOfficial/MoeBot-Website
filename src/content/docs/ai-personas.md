## 选择是否启用 AI

首次配置可以暂不启用 AI。关键词和插件命令仍可按自身配置运行，模型服务不是所有玩法的前提。

启用 AI 时，准备提供商 API 地址、API Key 和模型。调用费用与配额由对应提供商决定，CF 免费层也不等于模型免费。

## 配置提供商

在 WebUI 的 AI 服务中添加 OpenAI 兼容提供商，设置名称、基础地址、认证密钥和可用模型。支持按需拉取模型列表，是否可自动读取取决于提供商接口。

提供商认证信息保存在后端 Secret 中。不要将 API Key 放进官网、公开插件包或候补表单。

## 模型参数

按模型能力设置温度、输出长度等参数。供应商可能使用不同字段或拒绝某些参数，应以实际错误和其文档为准。

系统存在提供商/人格数量和单配置大小限制，详情见 [提供商配置参考](/docs/provider-options/)。

## 设置人格

人格用于定义机器人参与对话的语气与要求。先写清楚希望的行为、回复长度和场景，再逐步调整。

不同人格可选择对应提供商和模型。保存后重新部署，确认当前运行配置已生效再检查消息效果。

## 记忆和工具

会话记忆与主动发言由核心配置控制。MCP 需要单独启用和配置，不能因为 AI 已开就假定远程工具可调用。
