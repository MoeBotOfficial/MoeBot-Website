## 创建支持 Webhook 的机器人

在 [QQ 开放平台](https://q.qq.com) 创建官方机器人，并根据平台要求完成应用设置与权限准备。当前适配器处理群聊和私聊，使用官方 HTTP Webhook 入口。

WebUI 中手动填写 **AppID** 和 **AppSecret**。目前不提供扫码创建或自动绑定 QQ 应用的功能。

## 保存凭据

连接自己的 Pages 后端后，在适配器管理中填写 QQ 凭据。配置默认状态只显示是否已设置密钥；有 CF 编辑权限的管理员可以通过显式操作读取当前运行值。

填写后点击保存并部署，等待当前生产运行确认。不要把尚未部署的 CF 保存值当作已经生效的配置。

## 回调地址

标准入口是：

```text
https://你的后端地址/webhook/qq
```

后端兼容 `/webhook` 和 `/`，新应用建议使用规范入口 `/webhook/qq`。地址以 CF 返回的真实生产域名为准。

先确认 QQ 凭据已生效，再在平台回调配置里填写地址并验证。回调验证需要同步返回签名结果，不能只确认 `/health` 就认为平台已验证。

## 事件订阅与平台能力

| 使用方式 | 当前相关事件 |
| --- | --- |
| 群 @ 消息 | `GROUP_AT_MESSAGE_CREATE` |
| 群全量消息 | `GROUP_MESSAGE_CREATE`，需相应平台权限 |
| 私聊 | `C2C_MESSAGE_CREATE` |
| 按钮互动 | `INTERACTION_CREATE`，需相应按钮权限 |

普通自定义 Markdown 已开放，无需模板；QQ 自定义按钮仍需确认平台开通条件，并订阅互动事件。不能因为 Markdown 可用就假定键盘已开通。

## 如何确认接入成功

1. Pages 生产后端健康检查正确。
2. WebUI 确认配置和运行已匹配。
3. QQ 平台回调验证通过。
4. 在测试群或私聊发送消息，收到实际回复。

详细事件、回复额度与平台接口见 [QQ 平台接口说明](/docs/qq-api-notes/)。
