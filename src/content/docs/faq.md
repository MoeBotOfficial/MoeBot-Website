## 需要官网账号或激活吗？

不需要。候补名单只登记意向，独立于安装。官网也不会接收 CF、QQ 或模型密钥。

## 为什么打不开后端 Release？

核心和 WebUI 仓库目前私有，Release 也需要读取权限。内测安装包由维护者分发或由有权限用户下载；私有链接不能作为匿名下载地址。

## 可以从官网一键部署吗？

首版官网只提供静态内容与安装文档。它不触发私有 Actions，不接收 CF Token，也不保存部署任务。获取首装包后在自己的 CF Pages 上传，再用现有 WebUI 配置。

## WebUI 连接提示项目或权限错误

核对实际生产后端地址、CF 账户 ID、Pages 项目名和 Token。子域名可能被 CF 加后缀，建议用控制台返回的真实地址。

Token 需要对应账户的 Pages 编辑权限，数据库操作还需要 D1 编辑权限。错误中的 CF 返回码有助于区分项目不存在、权限不足和令牌失效。

## /health 正常，为什么 QQ 没有回复？

健康检查只确认后端程序。还要完成 D1 与 QQ 凭据部署、事件订阅、平台回调验证，并检查总开关和适配器开关。

在 QQ 发送一条测试消息后查看当前生产实时日志，不能把静态配置状态当作平台验证历史。

## 不想启用 AI 可以吗？

可以。关闭 AI 后仍能按配置使用关键词和插件命令。启用 AI 则需有效提供商、模型和 API Key。

## Markdown 有效，按钮却失败

Markdown 与按钮有各自授权，插件按钮还需要 QQ 平台开通条件和互动事件订阅。请检查 WebUI 授权与平台权限，详见 [Markdown 示例](/docs/developers/markdown-demo/)。

## 插件 ZIP 无法上传

下载对应 Release 的构建 ZIP，不能使用 Source code ZIP。核对三个根文件、API 版本、大小、命令冲突和当前核心能力。

## 更新会删除聊天记录吗？

正常 WebUI 更新恢复完整安装，D1 数据不会随代码替换。卸载插件默认保留插件数据；更换数据库不自动迁移，回滚代码不回滚数据。

## 免费层能一直免费运行吗？

Cloudflare 与模型服务有各自配额和费用。插件计算、JSON 解析、加密与数据库访问会消耗资源，不能承诺所有配置都在免费额度内。见 [Cloudflare 配额与限制](/docs/cloudflare-limits/)。
