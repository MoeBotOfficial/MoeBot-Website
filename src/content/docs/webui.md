## 连接自己的后端

[官方 WebUI](https://qq-bot-webui.vercel.app) 是静态控制台。它通过你提供的 CF Token 连接已有 Pages 后端的管理 API，配置和部署由浏览器与后端编排。

填写实际生产后端 URL 和 CF Token。首次未写入目标 ENV 时，按提示填写 CF 账户 ID 和 Pages 项目名。账户和项目会与当前后端核对，之后固定使用该目标。

CF Token 默认使用浏览器会话存储；勾选记住后可保存到本地存储。不要在公共设备上保存 Token。断开连接可清除已保存连接信息。

## 控制台主要模块

| 模块 | 用途 |
| --- | --- |
| AI 服务与人格 | 提供商、模型、参数、人格和默认选择 |
| 适配器管理 | QQ 凭据、平台开关与配置状态 |
| 关键词回复 | RE2 规则、Markdown、标签、按钮和面板 |
| 插件管理 | ZIP 上传、能力授权、配置、启停、范围、更新与卸载 |
| MCP 服务 | 工具检测、选择、认证、触发与启停 |
| 数据管理 | D1 创建、绑定、结构检查与只读浏览 |
| 日志管理 | 连接当前生产实时日志，不提供历史归档 |
| 更新程序 | 导入核心更新 JSON，保留完整安装集合 |

## 编辑、保存与运行

未保存的编辑作为草稿或待提交修改显示。普通插件草稿可在浏览器保存，密钥修改只保留在页面内存，刷新后可能需要重填。

点击保存并部署后，控制台会恢复安装集合、组装程序和加密恢复包，上传资源并应用配置。CF 设置保存与 Pages 部署不是原子操作。

只有目标生产部署 ID、build ID 和配置代次匹配后，页面才确认已生效。失败或等待时按控制台提示核实，不盲目重复首次安装。

## 数据和密钥边界

官网不会读取机器人数据或凭据。管理请求由你打开的 WebUI 与自己的后端处理。D1 数据浏览默认只读，取记录和计数由用户主动执行；更换数据库不自动迁移聊天记录。

详见 [管理与恢复协议](/docs/developers/management/) 与 [更新与恢复](/docs/upgrades/)。
