## 首装包和更新包

| 产物 | 正确用途 |
| --- | --- |
| `qq-bot-pages.zip` | 新项目首次安装 |
| `qq-bot-release.json` | 已有后端通过 WebUI 更新 |
| 插件 ZIP | 插件管理安装或同 ID 更新 |
| WebUI ZIP | 独立部署静态控制台 |

不要用首装包覆盖已有实例。0.8.6 首装包带默认关键词、无插件，覆盖会替换已有完整恢复产物。

## 更新已有后端

在 WebUI 更新程序中选择可信的核心更新 JSON。核心仓库私有，匿名检查公开 Release 无法下载；有权限用户下载后可本地导入。

WebUI 恢复当前核心、插件、普通配置和密钥操作，验证完整安装集合，然后组装部署。密钥按保持、替换、删除语义合并。

## 确认更新生效

提交之后，控制台核对目标生产部署 ID、程序 build ID 与配置代次。只完成 CF 设置保存还不能宣布生产生效。

待确认或超时先核实 CF 状态，避免盲目重装或覆盖密钥。保留草稿和可信产物，按控制台提示重新检查或重新部署已保存配置。

## 回滚与数据库

CF 回滚可以恢复旧代码与对应运行环境，但 D1 数据不会回滚。还应核对项目当前保存配置是否与运行版本一致。

数据库迁移和备份需要单独安排。更换绑定不自动搬迁聊天和插件数据，原库保留。

## WebUI 自身更新

官方控制台由维护者发布。独立部署者应下载新 WebUI Release，核验并关联原 Vercel 项目重新部署；未建立 Git 集成时，push 源码不会自动更新站点。

详情见 [独立部署 WebUI](/docs/webui-deployment/) 与 [管理与恢复协议](/docs/developers/management/)。
